Official Privacy Policy & Chrome Web Store Disclosures
v2.2.0 (Manifest V3) Updated: Sep 2026 Publisher: Calc Labz

1 Zero Cloud Data Collection

Siebel PDI Automator Pro does not collect, harvest, transmit, or monetize any user data, vehicle records, browsing history, or operational logs. The extension does not connect to any external cloud database, analytics service, or third-party tracking server. Every calculation, query, and automation runs 100% client-side inside your local browser memory.

2 Local Browser Storage Scope

The extension utilizes Google Chrome's sandboxed chrome.storage.local API to preserve operational state across browser reloads. The persisted data consists strictly of:

  • Active Queue Items — 17-digit VINs, battery numbers, assigned technician names, and target PDI statuses uploaded via your local CSV.
  • Inspection History — Timestamped success/failure counts and speeds for the last 5 completed batches (allowing 1-click failed VIN retries).
  • Operational Logs — Diagnostic log lines (capped at 200 rows) displayed on your local telemetry dashboard for troubleshooting.
  • UI Preferences — User selected speed profile (Turbo, Balanced, Safe) and audio/desktop alert settings.

All stored records remain encrypted within your local Chrome profile and can be permanently wiped at any time using the Reset button in the extension header.

3 Host Permissions Disclosure

In accordance with Google Chrome Web Store Developer Policies, the extension requests access only to https://connect.heromotocorp.biz/*. This permission is strictly required and utilized for two actions:

  • Injecting the DOM automation dispatcher directly into the active Oracle Siebel CRM frame to read vehicle fields, assign technicians, and submit PDI forms.
  • Performing local HTTP HEAD pings to Hero Connect's favicon to detect dealership internet loss, auto-pause the queue, and resume safely when connectivity returns.

The extension cannot access, read, or interact with any other website, tab, or domain in your browser.

4 Chrome Extension API Justifications

  • activeTab — Grants execution access solely to the currently focused Hero Connect Siebel tab upon user interaction.
  • scripting — Injects the helper automation routines into Siebel applet iframes.
  • storage — Manages local queue persistence, session history, and speed profiles.
  • sidePanel — Allows the extension UI to dock persistently in Chrome 116+ side-by-side with Hero Connect without auto-closing.
  • alarms — Runs a 1-minute background watchdog to recover from hung Siebel query states without freezing the browser.
  • notifications — Fires a local desktop notification banner when an automated batch completes.

5 Remote Code Execution Prohibition

In full compliance with Chrome Web Store Manifest V3 guidelines, Siebel PDI Automator Pro does not load, evaluate, or execute any remotely-hosted JavaScript. All logic, parsers, and UI components are packaged locally within the published extension archive.

6 Dealership IT & Corporate Compliance

The extension is designed for corporate IT approval at Hero MotoCorp authorized dealerships:

  • Does not store employee login passwords, dealer codes, or portal session tokens.
  • Does not record customer PII (Personal Identifiable Information) such as customer names, Aadhaar, PAN, or phone numbers.
  • Maintains non-destructive automation that follows standard Siebel form validation and commit rules.

7 Third-Party Dependencies

The extension UI loads the open-source Inter and JetBrains Mono typefaces from Google Fonts via standard CDN stylesheets. No user data or cookies are transmitted to Google Fonts.
